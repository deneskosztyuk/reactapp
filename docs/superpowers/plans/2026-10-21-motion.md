# Motion and Pixel Cursor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a pixel-art cursor with electron trail, a faint parallax PCB background with a one-time power-on, animated project sprites, and a timeline current pulse, all subtle and idle-free.

**Architecture:** Cheapest primitive per effect. CSS cursor images; a small fixed trail canvas that loops only while points live; a fixed background layer moved by one `transform` per scroll frame; CSS `steps()` sprite-sheet animation; a CSS-transitioned pulse element. Pure logic lives in `src/lib/pixelTrail.ts` and `src/lib/parallax.ts` so it can be checked in Node.

**Tech Stack:** Vite 5, React 19, TypeScript, Tailwind 3, Aseprite CLI (Lua), Node 24 (runs `.ts` checks directly).

**Spec:** `docs/superpowers/specs/2026-10-21-motion-design.md`

## Global Constraints

- Do not commit, branch or push. Leave every change uncommitted on `master` (project memory overrides any commit step a skill asks for).
- No new dependencies. JS gzip delta ≤ 6 KB; new PNGs < 15 KB total.
- Colors only: `board #181A1B`, `silk #E6E6DF`, `dim #9A9C95`, `trace #3A3D3F`, `outline #5A5D5F`, `gold #C9A44A`, `led #E5484D`, `glow #7A2C2F`, new `trace-faint #202325`.
- Pixel art reads `px` (CSS px per art px) from `usePixelScale()`; drawing only with `fillRect` on integer art coords; motion in whole art px or `steps()`.
- Loops stop when nothing animates; all listeners passive.
- `prefers-reduced-motion: reduce`: no trail, spark, parallax, power-on, sprite cycle or pulse. Pointer image stays.
- Cursor replacement and trail only when `(hover: hover) and (pointer: fine)` matches.
- Checks: Node assert scripts in the plan workspace (`node <file>.check.ts`), `pnpm typecheck`, `pnpm build`, browser checks on `http://localhost:5173` (launch config `vite-dev`).

## Review Focus

1. Browser zoom or window resize while the trail is mounted: canvas backing store resizes to the new art grid, old points cleared, no stretched pixels (Task 2).
2. Mouse leaves the window and re-enters elsewhere: no line drawn across the gap (Task 2).
3. Scrolling a long page fast: parallax offset wraps at one tile with no visible jump; no horizontal overflow at 320 px (Task 3).
4. Hovering a project then leaving mid-cycle: sprite returns to frame 0 (Task 4).
5. Switching timeline roles rapidly: the pulse restarts from its current marker, never stays visible after arriving (Task 5).

### Task 2: Pixel pointer and electron trail

**Files:**
- Create: `src/lib/pixelTrail.ts`, `src/components/CursorTrail.tsx`
- Modify: `src/index.css`, `src/App.tsx`, `tailwind.config.js` (`"trace-faint": "#202325"`)

**Interfaces:**
- Consumes: `usePixelScale(): number`, `useReducedMotion(): boolean`, `pixelLine(a: Point, b: Point): Point[]` and `Point` from `src/lib/pixelLine.ts`.
- Produces: `export interface TrailPoint { x: number; y: number; age: number }`; `export const TRAIL_LIFE = 14`, `LED_AGE = 5`, `MAX_TRAIL = 48`; `addMove(points: TrailPoint[], from: Point | null, to: Point): TrailPoint[]`; `ageTrail(points: TrailPoint[]): TrailPoint[]`; `diamond(cx: number, cy: number, r: number): Point[]`; default `CursorTrail()` (no props).

- [ ] **Step 1: Write the failing check `pixelTrail.check.ts`**

```ts
import assert from "node:assert/strict";
import { addMove, ageTrail, diamond, MAX_TRAIL, TRAIL_LIFE } from "../../../src/lib/pixelTrail.ts";
assert.deepEqual(addMove([], null, [5, 5]), []);
assert.deepEqual(addMove([], [0, 0], [3, 0]).map((p) => [p.x, p.y, p.age]), [[1, 0, 0], [2, 0, 0], [3, 0, 0]]);
assert.equal(addMove([], [0, 0], [100, 0]).length, MAX_TRAIL);
assert.deepEqual(addMove([], [0, 0], [100, 0]).at(-1), { x: 100, y: 0, age: 0 });
const aged = ageTrail([{ x: 0, y: 0, age: TRAIL_LIFE - 2 }, { x: 1, y: 0, age: TRAIL_LIFE - 1 }]);
assert.deepEqual(aged, [{ x: 0, y: 0, age: TRAIL_LIFE - 1 }]);
assert.deepEqual(diamond(10, 10, 0), [[10, 10]]);
assert.equal(diamond(10, 10, 2).length, 8);
assert.ok(diamond(10, 10, 2).every(([x, y]) => Math.abs(x - 10) + Math.abs(y - 10) === 2));
console.log("pixelTrail: pass");
```

- [ ] **Step 2: Run it** — Expected: FAIL, module not found.

- [ ] **Step 3: Implement `src/lib/pixelTrail.ts`** — `addMove` appends `pixelLine(from, to)` without its first point, keeps the last `MAX_TRAIL`; `ageTrail` increments and drops `age >= TRAIL_LIFE`; `diamond` returns unique points with `|dx|+|dy| = r`.

- [ ] **Step 4: Run it** — Expected: `pixelTrail: pass`.

- [ ] **Step 5: Cursor CSS in `src/index.css`**

Inside `@layer base`, scoped to `html.pixel-cursor`: `body` gets `cursor: url("./assets/cursors/arrow.png") 0 0, auto;` then `cursor: image-set(url("./assets/cursors/arrow.png") 1x, url("./assets/cursors/arrow@2x.png") 2x) 0 0, auto;`. Same pair with `arrow-link` for `a, button:not(:disabled), [role="tab"]`.

- [ ] **Step 6: Implement `CursorTrail.tsx`**

Renders nothing unless the fine-pointer query matches (tracked with a `change` listener). On mount adds `pixel-cursor` to `document.documentElement`, removes on unmount/query loss. Canvas: fixed top-left, `pointer-events: none`, `aria-hidden`, `z-index: 50`, backing `ceil(innerWidth/px) × ceil(innerHeight/px)`, CSS size backing × `px`, `image-rendering: pixelated`; on resize or `px` change re-size and clear points. Under reduced motion: pointer class only, no canvas. Listeners: `mousemove` → art point, `addMove`, start loop; `mouseout` with `relatedTarget === null` → last point `null`; `pointerdown` with `pointerType === "mouse"` → spark. Loop: 16 ms fixed step, accumulator clamped to 250 ms; `ageTrail`, sparks advance, `clearRect`, draw points (`age < LED_AGE` → `led`, else `glow`), sparks via `diamond(x, y, floor(frame/2))` in `gold` until radius 5; stop when empty.

- [ ] **Step 7: Mount in `App.tsx`** after `<footer>`, and add the `trace-faint` token.

- [ ] **Step 8: Verify**

`pnpm typecheck` → 0 errors. Browser 1280: `document.documentElement.classList.contains("pixel-cursor")` true; computed `cursor` of body contains `arrow`, of a link contains `arrow-link`. Move the mouse (computer hover at two points): trail canvas has `led` pixels, all canvas pixels are palette or transparent; after 1 s no non-transparent pixels and the loop stopped (patched `requestAnimationFrame` counter flat). Resize to 900 wide: canvas backing equals `ceil(900/px)`. Mobile preset: no `pixel-cursor` class, no canvas.
